# PRD：手机屏幕共享助手（Phone Screen Share Assistant）

- 版本：v1.0
- 日期：2026-09-20
- 状态：待评审
- 仓库：github.com/liSuini/Phone

## 1. 项目概述

开发一套完全自研的手机屏幕共享工具，将 Android 手机的屏幕画面与系统声音通过 WiFi 实时同步到电脑桌面客户端，支持在电脑端用鼠标对手机进行基础反向控制。

**一句话定位**：低延迟、高音画同步质量、可深度定制的 Android→PC 无线投屏工具。

## 2. 目标用户与场景

- 用户：本人（开发者自用为主）
- 核心场景：在电脑上观看手机播放的视频/直播，画面与声音同步，偶发用鼠标点击手机操作
- 使用环境：同一 WiFi 局域网内，手机与电脑直连

## 3. 用户故事

1. 作为用户，我想用手机扫码/电脑输入地址快速建立连接，无需复杂配置
2. 作为用户，我想在电脑上流畅看到手机屏幕，音画同步无感知差异
3. 作为用户，我想听到手机播放的声音（媒体类）
4. 作为用户，我想在电脑上用鼠标点击手机屏幕对应位置，手机同步响应
5. 作为用户，连接中断时我想得到明确提示并能一键重连
6. 作为用户，我想在电脑上看到手机状态（电量、设备名），确认连接的设备正确

## 4. 功能清单

### P0（必须，第一版核心）

| 编号 | 功能 | 说明 |
|------|------|------|
| F01 | 屏幕采集与推流 | Android 端 MediaProjection 采集屏幕，WebRTC H.264 推流 |
| F02 | 音频采集与推流 | AudioPlaybackCapture 采集媒体声音，Opus 推流 |
| F03 | 电脑端视频播放 | C# 客户端接收并渲染视频画面 |
| F04 | 电脑端音频播放 | C# 客户端接收并播放声音，与画面同步 |
| F05 | 二维码/IP 配对连接 | APP 展示二维码（IP+端口+配对码），电脑扫码或手输 |
| F06 | 鼠标点击反向控制 | 电脑端单击 → DataChannel 归一化坐标 → 无障碍模拟点击 |
| F07 | 连接状态管理 | 建连、断线提示、一键重连 |
| F08 | 权限三步引导 | 屏幕录制授权 → 音频捕获授权 → 无障碍开启（可选） |

## 5. 非功能需求

| 类别 | 要求 |
|------|------|
| 延迟 | 局域网内端到端（屏幕变化→画面呈现）≤ 200ms |
| 音画同步 | 主观无感知差异（WebRTC 内置 lip sync） |
| 分辨率 | 1080p@30fps 起步，支持手机原生分辨率 |
| 稳定性 | 连续投屏 2 小时无崩溃、无内存泄漏 |
| 兼容性 | Android 10+；Windows 10/11 x64 |
| 安全性 | 配对码校验防误连；WebRTC SRTP 加密传输 |
| 资源占用 | 电脑端 CPU ≤ 15%（i5 级别），内存 ≤ 300MB |

## 6. 验收标准

1. 手机播放视频，电脑端画面流畅（≥25fps），声音清晰，音画无感知偏差
2. 电脑端点击视频画面任意位置，手机对应位置在 100ms 内响应
3. 手机锁屏或撤销授权后，电脑端 3 秒内收到停止提示
4. WiFi 正常波动下投屏不中断；断网 10 秒后电脑端出现重连提示
5. 配对码错误时无法建连
6. 手机旋转后画面正常，点击坐标依然准确
7. 连续运行 2 小时，电脑端内存无持续增长

## 7. 约束与已知限制

- Android 10 以下手机不支持音频采集（仅画面可用）
- 音源 APP 可声明禁止被采集（如部分银行/视频 APP），此时无声属正常现象
- 无障碍服务被系统或安全软件关闭时反向控制失效，观看不受影响
- 仅支持局域网，不支持跨公网（二期可扩展 TURN）

## 8. 里程碑建议

- M1：跑通最小链路（屏幕画面 → 电脑显示，无音频无控制）
- M2：音频接入，音画同步验收
- M3：反向控制（点击）
- M4：稳定性打磨 + 断线重连 + 验收测试全通过
